# Release 3 – Umsetzungsstand

Stand 13.10.2026. Release 3 (Firmenfähigkeit, Marktreife SaaS, Integrationen) wird in Arbeitspaketen gebaut (`docs/arbeitspakete.md`). Je Story steht hier, was umgesetzt ist und welche Annahmen gelten. „Teilweise“ heißt: Kern umgesetzt, einzelne Akzeptanzkriterien sind offen oder hängen von einem externen Dienst ab.

**Zusammenfassung:** 39 Stories. Umgesetzt 32, davon mehrere mit einer Prüfung gegen echte Systeme oder einer anwaltlichen Prüfung als offenem Rest; teilweise 3 (R3-16 Teams Store, R3-11 anwaltliche Prüfung, R3-09 externer Pentest); offen 4 (R3-35 bis R3-38, Modul Vorschlagswesen, nicht gebaut). Externe Systeme sind in den Tests durch Attrappen ersetzt, bezahlte Dienste werden nicht genutzt.
